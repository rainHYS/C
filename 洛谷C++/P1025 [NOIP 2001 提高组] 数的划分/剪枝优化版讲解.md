# 🎯 整数划分问题 —— 非递减划分方案计数（剪枝优化版）

## 📌 题目简述

将一个整数 `n` 拆分为 `k` 个正整数之和，要求：

- 拆分出的每个数字都 ≥ 1；
- 数列非递减（如：1 2 2 合法，2 1 2 非法）；
- 求总共存在多少种合法拆分方案。

------

## 🧠 基本思路

使用 **递归 + 剪枝** 实现深度搜索所有合法组合。每一层代表当前要选第 `pos` 个数字：

- 每次选一个数字 `i`（非递减）；
- 当前和累加；
- 如果位置数满了，就判断总和是否等于 `n`。

------

## 🧾 变量解释

| 变量名       | 类型   | 含义                                          |
| ------------ | ------ | --------------------------------------------- |
| `n`          | `int`  | 要拆分的目标总数                              |
| `k`          | `int`  | 拆分为多少个数字                              |
| `cnt`        | `int`  | 合法方案计数器                                |
| `result[]`   | `int*` | 存放当前尝试的组合，如 result[1] 到 result[k] |
| `currentSum` | `int`  | 当前组合数字的累加和                          |
| `pos`        | `int`  | 当前选到第几个数字（从 1 到 k）               |

------

## 🚀 核心函数讲解

```cpp
void recDiv(int pos, int currentSum)
```

### 🔄 递归终止条件

```cpp
if (pos > k) {
    if (currentSum == n) cnt++;
    return;
}
```

- 当递归选了 `k` 个数字后：
  - 如果和刚好等于 `n`，说明这是一种合法方案；
  - 否则返回，丢弃这个方案。

------

### 🔍 枚举范围 & 剪枝

```cpp
int minValue = result[pos - 1];
for (int i = minValue; i <= n - currentSum - (k - pos); i++) {
```

#### 🔹 `minValue = result[pos - 1]`

- 保证非递减顺序（当前数 ≥ 上一个数）

#### 🔹 `n - currentSum - (k - pos)`

- 当前剩下的数字最多能取的值

- **解释**：当前已经加了 `currentSum`，还剩 `n - currentSum` 没凑齐；
   后面还要选 `k - pos` 个数字，每个至少为 `1`，所以我们当前 `i` 最大不能超过：

  ```
  当前最大 i = n - currentSum - (k - pos)
  ```

#### 🔎 示例

比如 `n = 7`, `k = 3`, 当前 `pos = 2`, `currentSum = 2`：

- 剩下的和 = `7 - 2 = 5`
- 后面还剩 `1` 个数（`k - pos = 1`），必须为正整数
- 所以当前最大能选 `i = 5 - 1 = 4`

------

### ✅ 更新状态 & 回溯

```cpp
result[pos] = i;
recDiv(pos + 1, currentSum + i);
```

------

## 🧪 示例运行过程（n=5, k=2）

```txt
目标：5 = ? + ?（非递减）
调用序列如下：

pos = 1, i ∈ [1..3]：
  i = 1 → pos=2, currentSum=1, i ∈ [1..3] → cnt++ for i=4
  i = 2 → pos=2, currentSum=2, i ∈ [2..3]
  i = 3 → pos=2, currentSum=3, i ∈ [3..2] ✘无解

最终方案为：
1 + 4
2 + 3
```

## 📘 main 函数说明

```cpp
result = new int[k + 1]();  // 多一位，下标从 1 开始
result[0] = 1;              // 保证 result[1] 最小从 1 开始
recDiv(1, 0);
```

- `result[0] = 1` 是为了让 `result[1] >= result[0]`，而不是从 0 开始，避免非法组合

------

## ✅ 总结

- 通过 `currentSum` 避免重复计算和；
- 利用剩余量剪枝，大大减少递归次数；
- 非递减保证组合唯一性；
- `cnt` 是最终计数。
