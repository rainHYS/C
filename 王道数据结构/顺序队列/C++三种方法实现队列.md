# **C++三种队列实现方法**：

------

## 🌟 总览对比

| 项目 / 特性     | 手动实现（结构体 + 数组）  | `vector` 实现                | `<queue>` STL 容器适配器            |
| --------------- | -------------------------- | ---------------------------- | ----------------------------------- |
| 实现难度        | ⭐⭐⭐（基础C语言思维）       | ⭐⭐（需要掌握 vector）        | ⭐（最简单）                         |
| 接口设计        | 手动写函数（如 `enQueue`） | 手动写函数（如 `push_back`） | 内建接口（如 `.push()`）            |
| 功能完整性      | ✅ 基本可用，边界需手动判断 | ✅ 功能完整，使用方便         | ✅ 最完整，稳定性最强                |
| 循环队列支持    | ✅ 需要手动处理 `%`         | ❌ 一般不做循环（直接扩容）   | ✅ 内部已经封装好                    |
| 内存管理        | ❌ 固定大小，满了要手动处理 | ✅ 自动扩容                   | ✅ 自动管理                          |
| 用于 BFS 等算法 | ✅ 适合训练逻辑             | ✅ 可行，但麻烦些             | ✅ 推荐，常用 `queue<pair<int,int>>` |

------

## 🧱 1. 手动实现（结构体 + 数组）

```cpp
#define maxSize 4
typedef struct {
    int data[maxSize];
    int front, rear;
} sqQueue;
```

- 需要手动处理队头/队尾索引
- 手动写 `initQueue/enQueue/deQueue/isEmpty`
- 循环队列靠 `%maxSize` 控制
- 适合初学者理解“队列原理”

**优点：** 理解扎实
**缺点：** 写起来繁琐，不通用，容易出错

------

## 📦 2. 用 `vector` 实现

```cpp
#include <vector>
vector<int> q;
```

手动实现队列的操作：

```cpp
q.push_back(x);  // 入队
x = q.front();   // 查看队头
q.erase(q.begin());  // 出队（效率低）
```

或更高效地用一个索引模拟：

```cpp
int front = 0;
q.push_back(x);   // 入队
x = q[front++];   // 出队（仅移动索引）
```

**优点：**

- 灵活、支持任意大小
- 动态内存管理好，不用固定 `maxSize`

**缺点：**

- 需要自己写逻辑，BFS 时不如 `queue` 方便
- `erase()` 删除 `begin()` 是线性时间，效率低

------

## 🚀 3. 使用 `<queue>`

```cpp
#include <queue>
queue<int> q;

q.push(10);       // 入队
int x = q.front(); // 查看队头
q.pop();          // 出队
```

**优点：**

- 语法最简单，BFS 最常用
- 自动处理内存、边界、安全性高
- 可以使用 `queue<pair<int,int>>` 做图搜索

**缺点：**

- 不支持随机访问
- 不能访问中间元素（但队列本就不需要）

------

## 🧠 总结建议

| 你的阶段 | 建议使用方式   | 原因                     |
| -------- | -------------- | ------------------------ |
| 入门阶段 | 手动实现       | 理解 FIFO 和循环队列     |
| 过渡阶段 | 使用 `vector`  | 理解动态内存和模拟机制   |
| 实战阶段 | 使用 `<queue>` | 快速编写 BFS、拓扑排序等 |

------

如果写 BFS，推荐直接使用 `<queue>`，逻辑清晰、代码简洁。而 `vector` 更适合用来管理路径、邻接表等数据结构。手动实现则是适用于408、828考研等试卷，可能会出代码填空题。
